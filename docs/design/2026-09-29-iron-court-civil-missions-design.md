# Iron Court - civil missions (Send an Envoy, Send Diplomats)

Date: 2026-09-29. Author request, after the Rome 2 comparison
(`docs/IRON_COURT_VS_ROME2.md`): "civil missions ... can be added". Choices made in chat, in order:

- Targets: **province and faction** ("Province and faction (Recommended)").
- Timing: **at once, effect lasts N turns** - paid and resolved on the click like the four
  errands; no "away" state for the man.
- Province effects: **Control, Armaments, Raw materials, Labour**, each its own mission.
- Placement: **B** - a fifth Intrigue column holding two cards; the four province tasks are
  chosen in a picker, not given four cards.
- Sections 1-5 of the design below were each presented in chat and answered "continue".

Rome 2 shape this follows: Organize Games / Send Emissary (a province, for some turns) and Send
Diplomats (a faction's relations). What it does not copy: the man going away for N turns.

## 1. What exists today

- **Moves** are rows of `IC.PLOTS` (`zzz_derpy_iron_court.lua`), each with `key`, `name`,
  `icon`, `cat`, `cost` (an `IC.TUNE` key), `effect`, `blurb`, and `aimed = false` for the
  four errands. `IC.plot_is_aimed` is "the target is a man"; `IC.is_civil_mission` is its
  negation and refuses a general (`can_plot`, reason `"commands"`).
- **Every move rolls** `IC.TUNE["plot_chance_" .. key]` (`IC.plot_chance`). The standing edge
  (`plot_chance_per_10`) is added only for an aimed move, because it compares two men.
- **The grid** (`zzz_derpy_iron_court_ui.lua`) is built from `IC.PLOT_CATS`: one column per
  category, depth = the longest column, card size derived from `CONTENT_W` (1884) and the
  floor at y 972. Today 4 columns x 4 deep, cards 459 x 176. Category `party` (Provoke, Purge)
  is not a column; those moves live on the Court card's buttons.
- **Pickers** (`ICUI.pick.kind`): `office`, `gov`, `house`, `plot_target` (a man to aim at),
  `plot` (the man who carries it out). `draw_picker` lists CHARACTERS only; the Governors tab
  (`draw_govs`) is the one place that draws province rows.
- **Refusals** come from the model (`IC.may_target`, `IC.can_plot`) and are worded by
  `ICUI.reason_text(why, spare)`; the picker asks the same two functions the click does.
- **Multiplayer**: a move is `IC.mp_send(faction, "plot", "plot|actor|target")`, split by
  `fields()` on `|`; `IC.MP_MAX = 100` characters for `"ic1|" .. op .. "|" .. arg`.
- **Messages**: `IC.feed(fk, "plot_ok"|"plot_fail", IC.move_result_key(key, ok))`, whose text is
  `event_feed_strings_text_derpy_ic_move_<key>_ok|_fail`, generated by `gen_iron_court.py`.
- **Province bundles**: `cm:apply_effect_bundle_to_faction_province(bundle, region, turns)`, a
  REGION interface, as the governor bundles use it. `IC.held_region(faction_key, province_key)`
  finds a held region in a province.
- **The diplomatic bonus**: `cm:apply_dilemma_diplomatic_bonus(a, b, n)`, n in -6..+6, already
  used by `IC.rebel_sour`; the harness stub records it and refuses n outside -6..+6.

## 2. The two cards

A new category, `{key = "mission", name = "Missions"}`, appended to `IC.PLOT_CATS`. The grid
becomes 5 columns x 4 deep; cards 364 x 176. `gen_ic_ui.py --check` (20d) decides which of the
existing sixteen cards' text must be trimmed to fit the narrower card.

### 2.1 Send an Envoy (province)

One `IC.PLOTS` row, `key = "envoy"`, `cat = "mission"`, `aimed = false`, `target = "province"`,
one price. Its four tasks are a separate table, `IC.ENVOY_TASKS`, in display order:

| code | name | effect | bundle |
|---|---|---|---|
| `ctl` | Control | +6 control | `derpy_ic_envoy_ctl` |
| `arm` | Armaments | +20% armaments production | `derpy_ic_envoy_arm` |
| `raw` | Raw materials | +20% raw material efficiency | `derpy_ic_envoy_raw` |
| `lab` | Labour | -15% labourers lost | `derpy_ic_envoy_lab` |

The target is the string `province_key .. ":" .. code`. The codes are three letters so the
longest vanilla province key (`wh3_main_combi_province_southlands_worlds_edge_mountains`, 56
characters) sends as 82 of the 100 `IC.MP_MAX` allows.

Flow (three pickers, in the order Bribe already asks two):
1. `kind = "envoy_province"` - **Which province?** Every province `IC.seats` returns. Columns:
   province name; its control now; who governs it (the Governors tab's own cell text); the
   tasks running there with turns left.
2. `kind = "envoy_task"` - **What does he do in {province}?** Four rows, one per task: name,
   effect line, and "Running N" (refused) when that task's bundle is already on the province.
3. `kind = "plot"` - **Who carries this out?** The existing list, `ICUI.pick.key` set to the
   `province:code` target.

### 2.2 Send Diplomats (faction)

One `IC.PLOTS` row, `key = "diplomats"`, `cat = "mission"`, `aimed = false`,
`target = "faction"`. The target is a faction key.

Flow:
1. `kind = "diplomats_faction"` - **To whom?** Every faction `faction:factions_met()` returns
   for the player. Columns: faction name; how they regard you now
   (`target:diplomatic_attitude_towards(player_key)`, the figure the diplomacy screen shows);
   at war or not; the rest if any.
2. `kind = "plot"` - **Who carries this out?** As above.

## 3. Numbers

Every number is an `IC.TUNE` knob, NOT an MCT setting and NOT in `IC.TUNE_ORDER`, so no save
string changes for any of them.

| knob | value | why |
|---|---|---|
| `mission_turns` | 5 | the bundle's duration |
| `plot_envoy_cost` | 120 | beside Provoke 120; above Ride the Circuit 110, below Hold the Ash Court 140 |
| `plot_chance_envoy` | 80 | Ride the Circuit rolls 80 |
| `envoy_ctl` | 6 | CA's Smoke Stacks edict +2; the governor +2, +4 for a Crown man |
| `envoy_arm` | 20 | CA's Higher Quotas edict +10%; a Tower seat +5% |
| `envoy_raw` | 20 | the Drill's reward +10%; a Tower seat +5% |
| `envoy_lab` | 15 | shipped as -15; CA's mood bundles add +3% (jubilant) to +20% (outraged) |
| `plot_diplomats_cost` | 100 | |
| `plot_chance_diplomats` | 75 | Hold the Ash Court rolls 75 |
| `diplomats_bonus` | 4 | CA uses -2 (Intrigue at the Court), -3 (Web of Power), +6 (Covens, commented "+30") |
| `diplomats_rest` | 5 | turns before the same faction may be sent to again |

The envoy values are roughly double CA's permanent versions because they last 5 turns and cost
a man's influence.

## 4. Model

### 4.1 Targets - `IC.may_target`

A branch on `plot.target`, placed BEFORE the `if not IC.plot_is_aimed(plot_key) then return
true end` line, so the pickers and the click ask one rule:

- `province`: split the target on `:`. Refused `"gone"` if the province is not in
  `IC.seats(faction_key)` (lost between picking and clicking); `"no such task"` for an unknown
  code; `"running", turns` if `region:faction_province_has_effect_bundle(bundle)` for the
  region `IC.held_region` returns - the turns read off `faction_province_effect_bundles()`,
  the entry whose `key()` is the bundle, its `duration()`.
- `faction`: refused `"gone"` if the faction is missing or dead; `"unmet"` if not in the
  player's `factions_met()`; `"rebel"` if `is_rebel()`; `"player"` if it is a human faction;
  `"resting", turns` if `court.sent[target]` is within `diplomats_rest` turns; the player's own
  key is `"gone"` too (it is never listed).

`may_target` returns a third value (the turns) for `running` and `resting`; `can_plot` passes it
through as its `short` value, and `ICUI.reason_text(why, spare)` words it.

### 4.2 Effects - `IC.plot`

On success:
- `envoy`: `cm:apply_effect_bundle_to_faction_province(task.bundle, region,
  IC.TUNE.mission_turns)`.
- `diplomats`: `cm:apply_dilemma_diplomatic_bonus(faction_key, target,
  IC.TUNE.diplomats_bonus)`, then `court.sent[target] = turn`. (Corrected at the final review:
  this line first read `(target, faction_key, ...)`. CA's doc says only "first" and "second", but
  all five of CA's calls put the one who acts first and the faction whose regard moves second.)

On success or failure the price is paid and the move logged, as every move is today. The rest is
set on SUCCESS only: a failed send bought nothing, and resting the faction as well would charge
twice.

### 4.3 Saved state

`court.sent`, faction key -> turn sent, is the only new state. It is packed the way the court's
other key -> number maps are, as a new field APPENDED to the court string, so a save written
before this build loads with `court.sent = {}`. Entries older than `diplomats_rest` are dropped
when saved, so the field never grows past the factions sent to in the last 5 turns.

### 4.4 Not reached by the AI

AI courts never send either move; nothing in `zzz_derpy_iron_court_parties.lua` names them.

## 5. Panel

- **Card click** (`ICUI.on_plot_click`): a move with `target = "province"` opens
  `envoy_province`; `target = "faction"` opens `diplomats_faction`; everything else as today.
- **Picker rows** for the three new kinds are drawn by a new branch of `ICUI.draw_picker`, not
  by the character loop. The province and task rows reuse the Governors tab's cell text for
  province name, control and governor. Each row is refused by asking `IC.may_target` with the
  target it would send, and labelled from the refusal: `Running N`, `Rest N`, `Rebel`,
  `Player`, `No`.
- **Picker titles** (`ICUI.pick_title`): "Send an Envoy - to which province?", "Send an Envoy
  - what does he do in {province}?", "Send Diplomats - to whom?"; the existing "Who carries
  this out? {label} - spends N influence" for the third step, with `ICUI.plot_label` naming the
  province and task, or the faction.
- **Reason sentences** (`ICUI.reason_text`): `running` - "That work is already under way there,
  for another N turns."; `resting` - "Your diplomats were there N turns ago. Send again in N
  turns."; `gone` - "That province or faction is no longer there to send to."; `unmet`, `rebel`,
  `player`, `no such task` - one sentence each.
- **Log tab** (`ICUI.intrigue_text`): kinds `envoy` and `diplomats`. Success: "{man} went to
  {province}: +20% armaments for 5 turns." / "{man} went to {faction}'s court: their regard for
  you rose." Failure: "{man} went to {province} and came back with nothing: N influence
  spent."
- **Help page**: the errands line gains the two missions if the fit check allows; otherwise
  its own line.
- **Not added**: no running-mission column on the Governors tab. The province's own effects
  list and the Envoy's province picker both show it; a third place is the duplicated figure the
  audit rule warns about.

## 6. Data (`gen_iron_court.py`)

- Four `effect_bundles` rows and their `effect_bundles_to_effects_junctions` rows, each bundle
  the SHAPE CA ships for a bundle put on one Chaos Dwarf province: `bundle_target = province`,
  `is_global_effect = true`, `owner_only = true` (CA's Higher Quotas edict and its mood
  bundles, read from the vanilla cache), and every effect scoped
  `province_to_province_own_unseen`, the scope those bundles give it. This follows the
  governor income ruling (a payload on ONE province scopes its effects `province_to_*`) and
  keeps all four bundles one shape rather than mixing the governor bundle's faction target in:
  - control: `wh_main_effect_public_order_edict` - CA's Smoke Stacks edict;
  - armaments: `wh3_dlc23_pooled_resource_chd_armaments_modifier` - CA's Higher Quotas edict;
  - raw materials: `wh3_dlc23_pooled_resource_chd_raw_material_efficiency` - the least certain
    of the four: CA's only `province_to_*` use of this effect is the Drill's `_factionwide`
    scope, which would reach every province, so the edict scope is borrowed;
  - labour: `wh3_dlc23_pooled_resource_chd_increased_labour_loss` - CA's mood bundles.
- Title and description loc for each (`effect_bundles_localised_title_<key>`,
  `..._description_<key>`) - the effect panel reads the loc, not the row.
- Four event texts: `event_feed_strings_text_derpy_ic_move_envoy_ok|_fail`,
  `..._diplomats_ok|_fail`.
- Bundle icons, CA's own: control `wh3_dlc23_edict_chd_smoke_stacks.png`, armaments
  `wh3_dlc23_edict_chd_higher_quotas.png`, raw materials `chd_toz_district_industry.png`,
  labour `public_order_jubilant.png`.

## 7. Multiplayer

Both moves ride the existing `plot` action. The target is text; every machine runs the same
`IC.plot`, so the bundle and the bonus land on both, and the roll is `cm:random_number`, which
is synced. A check pins the longest vanilla province key under `IC.MP_MAX`.

## 8. Testing

Each check watched failing before its code goes in (`tools/_iron_court_harness.lua`):

- Envoy: applies the chosen task's bundle to a region of that province for `mission_turns`;
  refused while running (with the turns), for a province not held, for a general, for an
  unknown task code; price paid on success and on failure; a failure applies nothing.
- Diplomats: the bonus call is (target, player, `diplomats_bonus`); resting refuses a second
  send inside `diplomats_rest` turns and allows it after; a failed send sets no rest; the rest
  round-trips a save and an old save string loads with none; rebels, humans, the dead and the
  unmet are refused.
- Multiplayer: `province:code` survives `fields()`; the longest vanilla province key fits.
- Panel: five columns, two new cards; Envoy walks province -> task -> man, Diplomats faction
  -> man; `Running N` and `Rest N` rows; Log lines name the province or the faction.
- Harness stubs gained: `region:faction_province_has_effect_bundle`,
  `region:faction_province_effect_bundles()` with `key()`/`duration()`, `faction:factions_met()`
  on the player, `diplomatic_attitude_towards`. `apply_effect_bundle_to_faction_province` is
  recorded with its turns.
- Mutants (`tools/mutate_iron_court.py`) for every branch; each must be caught.

Other gates: `check_effect_bundle_loc.py`, `check_effect_signs.py` (Labour's -15 must list as a
benefit), `gen_ic_ui.py --check` and `--selftest`, `import_iron_court.py`, the full mutation
run; `preview_iron_court.py` for a picture of the five-column grid before it ships.

**Only the game can confirm the scopes.** The handoff lists five in-game looks: the bundle is in
the province's effects with its turns; the control breakdown names the gain sensibly (the edict
effect may label it as an edict's; if it does, the control row moves to the governor's
`wh_main_effect_public_order_faction` and its bundle to the governor's faction target);
armaments and raw materials move; the labour figure moves; the diplomacy screen shows the
modifier.

## 9. Out of scope

- The man going away for N turns (Rome 2's way; declined for "at once").
- Missions for AI courts.
- A Governors-tab column for running missions.
- Different prices per Envoy task (the card would have to read "from N").
- The political influence map (a separate spec, next) and the Dignitary (parked).
